# E-Commerce Automation & Shopify Integration Scripts

This repository contains Python automation scripts designed to streamline e-commerce tasks, replace repetitive manual spreadsheet work, and sync operational data via API.

## Tech Stack & Tools
- **Language:** Python 3
- **E-commerce Platform:** Shopify REST API
- **Data Handling:** Pandas, Requests, JSON, CSV processing
- **Environment:** Google Colab / Cloud Execution

## Key Features
- **Automated Data Extraction:** Fetch product and inventory levels directly via the Shopify REST API.
- **Spreadsheet Cleaning:** Convert raw JSON responses into structured Pandas DataFrames and clean CSV reports.
- **Async Workflow:** Built for lightweight, cloud-based, and asynchronous execution.
